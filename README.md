# Spring Boot Employee Book

A simple Spring Boot application to manage employees:  
- Search for employees  
- Add new employees  
- Remove employees  

#### Endpoints 
| **Method** | **Endpoint** | **Description** | 
| --- | --- | --- |
| **GET** | `/add` | Add an employee | 
| **GET** | `/remove` | Remove an employee | 
| **GET** | `/find` | Find an employee | 
| **GET** | `/` | View all employees |”
